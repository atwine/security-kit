# Security policy

If you find a security hole in the security kit (its workflows, checks,
watcher or templates), please tell us privately first, so it can be fixed
before anyone misuses it.

**How to report:** use GitHub's private form at
<https://github.com/atwine/security-kit/security/advisories/new>. Include
what you found, how to reproduce it, and what it lets someone do (for
example, make a project's checks pass without checking, or change what the
watcher's issue says).

**What happens next:** we confirm we got your report within 5 working
days, keep you told of progress, and credit you when it's fixed, unless
you'd rather we didn't.

**Please don't:** test against projects that use the kit, or open a public
issue or pull request about the hole before it's fixed. A fork of this
repository is the right place to try things.

Only the latest release gets fixes.
